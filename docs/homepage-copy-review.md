# Пересмотр текста главной страницы

Источник: `unroot-homepage-source.html`, предоставленный владельцем сайта.

## Что стоит перенять

- Сначала показать дизайн, затем предложить полный проект: «You send the link … Then you decide if we build the rest» — ясная последовательность покупки.
- Точный состав Concept: одно направление в Figma, hero + три секции, анимированный scroll preview. Цена $1,499, семь дней, без правок и разработки.
- Условия продолжения: файл остаётся клиенту; $1,499 засчитываются в полный редизайн в течение 60 дней.
- Формат совместной работы: прямой контакт, Slack, ежедневный прогресс для Sprint, еженедельные обновления для месячного проекта.
- Конкретные действия в кейсах: например, миграция Javelin с WordPress на Webflow, бренд и сайт Workshop, CMS и передача проекта.
- Имена команды, роли и исходные отзывы со ссылками. Цитаты клиентов не редактировались.

## Что переписать и почему

| Исходный подход | Новая формулировка / решение | Причина |
| --- | --- | --- |
| «1 direction. One shot.» | «A defined scope. A file you keep.» | Объясняет состав покупки вместо бравады. |
| «No brief. No moodboard. No discovery call.» | Сначала перечислить результат. Возможность начать без формального брифа объяснить в FAQ. | Главное — что клиент получает. |
| «digital foundation», «next-gen», «transforming» | Назвать услугу и продукт клиента: website, brand identity, migration. | Убирает общие оценочные слова. |
| «The full thing» | «Monthly Design & Build», четыре недели, состав команды и объём. | Задаёт понятные границы. |
| «Pick whatever is on fire» | «Work on your agreed priorities.» | Объясняет формат Sprint без драматизации. |
| «If it is wrong … we shake hands» | Файлы остаются клиенту независимо от продолжения. | Прямое описание условий. |
| «We vibe code … a month is enough for a full website» | Отдельно описать AI-assisted coding и ответственность команды. | Использование инструмента само по себе не обосновывает сроки. |
| «2 slots left in October / December» | «Send us your website.» | Не закрепляет в статическом тексте непроверенное число свободных мест. |

## Как разделены предложения

**Homepage Concept — $1,499**

Фиксированный результат: одно направление главной страницы. Срок — второстепенная подпись «7-day delivery». Подходит, когда нужно выбрать направление редизайна. В стоимость не входит разработка и правки.

**Design & Build Sprint — $2,499**

Одна рабочая неделя над согласованными задачами. Подходит, когда задачи уже понятны. Не обещает закончить любой объём за неделю. Прямой контакт и ежедневный прогресс. Продление не обязательно.

**Monthly Design & Build — $7,899**

Четыре недели с дизайнером, разработчиком и арт-дирекцией. Сохранён объём из исходника: дизайн и сборка лендинга либо дизайн многостраничного сайта. Не обещается разработка всего многостраничного сайта за месяц. Неограниченная подача задач отделена от их приоритизации внутри оплаченного срока.

## Что применено

Переписаны пояснения первого экрана, Concept, процесса, тарифов, кейсов, услуг, команды, FAQ и финального действия. Заголовок первого экрана: «Websites for AI and tech startups». Добавлен прямой ответ на вопрос о разнице между Concept и Sprint.

Сохранены цены и подтверждённые владельцем условия, отзывы и ссылки на Trustpilot. Метрики «9 years», «100+ brands», «$130M+ raised by clients» взяты из предоставленного материала; новой проверки этих бизнес-данных не проводилось.

## Визуальная иерархия

Google Sans подключён локально для всех страниц: четыре начертания 400–700. Кремовый `#F6C9B6` выделяет основное действие и фиксированное предложение; насыщенный `#D99C7C` используется для границ и hover; светлые `#FFEFE6` и `#F8DDCD` собирают связанные элементы; тёмный `#21153D` задаёт контраст. Все оттенки взяты из предоставленного HTML, структура предыдущего шага сохранена.
